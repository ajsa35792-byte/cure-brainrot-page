# Install Cure Brainrot 2.6

1. Download `cure-brainrot-2.6.zip`.
2. Unzip it (you get a folder called `cure-brainrot-2.6`).
3. Open `chrome://extensions` in Chrome.
4. Turn on **Developer mode** (top right).
5. Click **Load unpacked** and choose the unzipped `cure-brainrot-2.6` folder.

The AI key is optional. Without it you get built-in questions.
